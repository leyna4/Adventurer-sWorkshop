# 🎮 Adventurer’s Workshop

Adventurer’s Workshop is a mobile fantasy themed match 3 puzzle prototype developed in Unity.

Players repair broken magical items by collecting required materials through match 3 gameplay. After completing repairs, players earn coins and progress to the next customer.

---

# 📱 Platform
Android (Mobile Portrait)

---

# 🎯 Core Gameplay Loop

1. Customer arrives with a broken item
2. Required materials are displayed
3. Player collects materials through match 3 gameplay
4. Item gets repaired
5. Player earns coins
6. Next customer arrives

---

# ⚙️ Implemented Mechanics

- Match 3 collect system
- Material collection objectives
- Customer order system
- Coin reward system
- Limited move system
- Obstacle cube mechanic
- Level transition system
- Main menu and pause menu
- Mobile UI support
- Safe Area implementation
- DOTween animations and juice effects

---

# 🧊 Obstacle System

Some materials are trapped inside magical protection cubes.

Rules:
- Cubes cannot move
- Cubes break after 2 adjacent matches
- Materials inside cubes become collectible after breaking

---

# 📦 Prototype Scope

- 2 playable levels
- 2 customers
- 2 repairable items
- 3 material types
- 1 obstacle type

# ✂️ Cut Features

The following ideas were planned but removed due to scope limitations:

- Shop system
- More obstacle types
- Additional customers
- Advanced combo mechanics

These features were cut to focus on polish and mobile usability.

---

# 🔄 What Changed and Why

The original concept was simplified into a focused 2 level prototype.

Changes made during development:
- Reduced overall content scope
- Simplified progression system
- Improved mobile readability
- Added obstacle cube mechanic for clearer visual feedback
- Focused more on polish and gameplay feel

These changes helped create a more stable and polished prototype within the project timeframe.
